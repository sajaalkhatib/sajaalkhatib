## About Me

I'm a **Full-Stack .NET Developer** and Computer Science graduate who enjoys building web applications from the database layer to the user interface.

My strongest experience is with **C#, ASP.NET Core, ASP.NET MVC, Entity Framework Core, LINQ, Angular, TypeScript, and SQL**.

I enjoy solving problems, designing database-driven applications, building APIs, and creating clean and responsive interfaces.

Currently, I'm focused on growing as a software engineer through real-world projects, deeper backend knowledge, better database design, and continuous learning.
